Nori (`mascot.svg`) is an original lightweight TCF Quest illustration.

Original learning texts, scripts, explanations and illustration: CC BY 4.0 (attribution: TCF Quest). License: https://creativecommons.org/licenses/by/4.0/

No human audio recordings, remote fonts or third-party UI assets are bundled. Browser speech synthesis uses an installed voice; offline availability depends on the system. Imported recordings are supplied by the user and remain in IndexedDB. Their rights and correspondence to the script are not independently verified.

Future licensed recordings may be placed in `assets/audio/` and referenced with an `audio` field in a question object. The application currently generates questions from the compact pack rows; see the extension instructions in README.md.
